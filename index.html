GPA Planner

Pick a grade for each class to see your term and overall GPA. Add prior credit for a cumulative estimate, or use the goal calculator for target planning. GPA is unit-weighted (UC Berkeley method): total grade points ÷ total graded units; P/NP classes are excluded. Choices are saved separately and never change your Gradebook.

GradeCraft — Changelog

Chronological record of releases and commits (v1_1 → v1_19).

Latest: v1_19
v1_19 11/21/2026

Extended the GPA Planner with Prior Credit (graded units + GPA) and a Cumulative GPA row that folds that credit into the unit-weighted total, plus a Goal Calculator that estimates the average GPA needed on future units to hit a target cumulative GPA (with clear unreachable / already-met messaging and the formula shown). Prior and goal fields live only in the planner localStorage record; Clear All Grades keeps them.

v1_18 11/21/2026

Added grading policy rules per assignment group: drop lowest N, best N of M, late penalty (%/day with cap), score replacement, and extra credit. Group math now runs through computeGroupResult (late → replace → drop/best-of → extra credit), with a Policies menu, active-rule badges, assignment late/EC flags, and Target Forecaster notes when drop rules make the needed average approximate. Covered by new Vitest policy tests; legacy saves migrate empty policies on load.

v1_17 11/21/2026

Implemented Quality Foundation: extracted calculation and storage logic into standalone modules (src/calc.js, src/storage.js, src/constants.js), added a comprehensive test suite with 74 Vitest unit tests covering GPA math, unit weighting, and migration, automated Playwright browser smoke and accessibility checks, set up a GitHub Actions CI workflow, and added accessibility improvements (polite live toast announcements, keyboard group reordering, and reduced-motion support).

v1_16_4 11/20/2026

Fixed duplicate classes (such as CS 61A and DATA C8) appearing on open or after JSON import: saved data is now the only source once it exists, so older storage keys no longer re-add classes, and classes with the same ID or the same code, term and title are merged on load and import. Default examples are now CS 61A and DATA C8 only (MATH 54 removed), and the Restore Demo Courses message lists the examples it checks.

v1_16_3 11/18/2026

Set the release date for v1_1 through v1_12 to 11/16/2026 and switched all changelog dates (cards and raw log) to the mm/dd/yyyy format.

v1_16_2 11/18/2026

Removed hardcoded values from the Profile & Settings inputs (Display Name, Academic Email, Institution, and Major / Program now show placeholders only, and legacy filler values saved by older versions are cleared on load), added a release date to every changelog entry and raw log line, fixed the raw log so every entry renders inside its block, and made the Raw Plain-Text Changelog a collapsible dropdown.

v1_16_1 11/17/2026

Added a per-class P/NP checkbox next to Units that excludes P/NP courses from Term and Overall GPA while still counting their units toward total units, updated the GPA Planner with P/NP tags, P/NP grade dropdowns, and excluded P/NP counts in summary footers, pinned the + New Term button to the far right over a single horizontally scrolling term chip row with right-edge clearance padding, and widened Course Title by reducing Academic Term to half width.

v1_16 11/17/2026

Added per-class Units (0–20 in 0.5-unit steps, defaulting to 4 for new, duplicated, imported, and existing classes) and updated Term and Overall GPAs to be unit-weighted (excluding ungraded and 0-unit classes). Gradebook term tabs and All Terms now show total units alongside weighted GPA, and the GPA Planner includes a read-only Units column, weighted summaries, and a method note.

v1_15_3 11/17/2026

Removed redundant "+" and "←" symbols from the New Term, Add Class and Back to Gradebook button labels (the icons already convey the action).

v1_15_2 11/17/2026

Added a dedicated GPA Planner page (#/gpa) with a header navigation button: classes are listed by academic term with course code, title, and a grade drop-down, followed by a Term GPA per term and an Overall GPA. Planner grades are saved as a separate localStorage record and never modify the Gradebook.

v1_12 11/16/2026

Set the Gradebook dashboard as the main landing page (/GradeCraft/), separated Profile & Settings (#/profile / profile.html) and Changelog (#/changelog / changelog.html) into dedicated subpages with URL routing, and updated the top-left GradeCraft graduation cap brand button to navigate directly to the main landing page (https://maksymstesev.github.io/GradeCraft/).

v1_11 11/16/2026

Added footer "Changelog" link leading to a dedicated text-based Changelog page (v1_1 through v1_11).

v1_10 11/16/2026

Added drag-and-drop reordering for Assignment Groups via left slider icon handles and expanded the Class Grade Bucket Distribution card to stretch and fill 100% of its dedicated vertical and horizontal space.

v1_9 11/16/2026

Added Academic Term tab bar (Fall 2026, Spring 2026, All Terms, New Term) with Term GPA calculation, unified document-level event delegation, preserved saved localStorage course data alongside CS 61A, DATA C8, and MATH 54 templates, and removed the "Academic Standing" field from Profile & Settings.

v1_8 11/16/2026

Organized archived index.html versions into a local ignored folder via .gitignore.

v1_7 11/16/2026

Preserved input focus, caret position, and scroll state during in-place editing of assignment group names, weights, and scores.

v1_6 11/16/2026

Replaced all personal details in defaults and placeholders with generic academic filler data (Student Name, student@university.edu, generic IDs).

v1_5 11/16/2026

Added top-left graduation cap icon page reload trigger, set official UC Berkeley Registrar Grade Definitions (A+ through F with 4.0-scale grade points) as the default scale, and added a Custom Grade Definitions editor in Profile & Settings.

v1_4 11/16/2026

Configured root index.html deployment structure for GitHub Pages hosting.

v1_3 11/16/2026

Created separate Profile & Settings page containing the 3-way theme switcher, language & locale cascade selector, authentication UI placeholder skeleton, and JSON backup management; resolved null-reference event listener binding issues.

v1_2 11/16/2026

Added high-contrast True Black OLED theme as the default appearance alongside Midnight and Light themes.

v1_1 11/16/2026

Initial release of GradeCraft Class Grade Calculator & Forecaster: multi-class tabs, assignment group weights, grade bucket distribution, grouped & sorted assignment entries, percentage & letter grade calculation, What-If score overrides, Target Grade Forecaster, and localStorage persistence with JSON import/export.
