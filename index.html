Privacy note

When Sync is on and you sign in, GradeCraft stores your classes (groups, policies, assignments, due dates, What-If scores), GPA Planner choices (including prior credit and goals), profile fields, theme, locale and custom grade scale in your Firebase project under users/{your uid}. With Sync enabled, Firebase Analytics may also collect standard usage metrics in your project (measurementId). GradeCraft does not sell that data. The app works fully without an account. Delete my data removes your cloud documents and then the Firebase account (you may need to sign in again first).

Data Management & Local Backup

Export your classes and custom grade definitions as JSON or CSV, import a backup, restore default courses alongside your own, or factory reset.

GPA Planner

Pick a grade for each class to see your term and overall GPA. Add prior credit for a cumulative estimate, or use the goal calculator for target planning. GPA is unit-weighted: total grade points ÷ total graded units; P/NP classes are excluded. Choices are saved separately and never change your Gradebook.

GradeCraft — Changelog

Chronological record of releases and commits (v1_1 → v1_26_1).

Latest: v1_26_1
v1_26_1 11/22/2026

Locked down Firebase with App Check (reCAPTCHA Enterprise): client initializes ReCaptchaEnterpriseProvider from config, with optional localhost debug tokens. Documented HTTP-referrer API key restrictions for the GitHub Pages and local hosts.

v1_26 11/22/2026

Added institution presets for all UC undergraduate campuses (Berkeley default plus Davis, UCLA, San Diego, Santa Barbara, Irvine, Santa Cruz, Riverside, Merced): grade-point scales, semester/quarter unit notes, P/NP guidance, Apply / Export / Import JSON, and GPA Planner display decimals that follow the active preset (UCSD omits D+/D−).

v1_25 11/22/2026

Added Undo for deleted classes: a full in-memory snapshot is kept until the next page navigation, with a high-contrast orange Undo toast so a mistaken delete can be reversed without a recycle bin.

v1_24 11/22/2026

Added optional cloud sync and accounts (Firebase Auth + Firestore) behind a Sync (beta) toggle: email-link and Google sign-in, debounced batched uploads, real-time listeners, first-sign-in cloud/device/merge choice with local backup, deletion markers, privacy note, Sign out and Delete my data. App stays fully usable offline/local without config; paste a Spark web config to enable.

v1_23 11/22/2026

Added Import from Syllabus (rule-based, no LLM): paste a grading section or drop a PDF (pdf.js, on-device), parse name + percent pairs, review/edit proposed groups with a ~100% weight check, then create groups only on confirm. Optional LLM extraction is deferred.

v1_22 11/22/2026

Added Share & Export: print/PDF styles for the GPA Planner and Changelog, assignments CSV export (quoted fields, one row per assignment), and a read-only planner share link that compresses data into the URL with lz-string (file download fallback when too long). Opening a share link never writes to localStorage.

v1_21 11/22/2026

Added Charts & Trends: per-class stacked bars for points earned / lost / still to come, a grade-over-time line from dated scores, and a Term GPA trend chart on the GPA Planner. Each chart includes a text summary and data-table fallback, with SVG colors drawn from theme CSS variables.

v1_20 11/22/2026

Added optional due dates on assignments, an Upcoming panel (next 14 days + overdue, ranked by weight at stake across all classes), unified-view sort by due date, and .ics calendar export with stable UIDs and class/weight descriptions. Legacy saves migrate an empty due field on load.

v1_19 11/21/2026

Extended the GPA Planner with Prior Credit (graded units + GPA) and a Cumulative GPA row that folds that credit into the unit-weighted total, plus a Goal Calculator that estimates the average GPA needed on future units to hit a target cumulative GPA (with clear unreachable / already-met messaging and the formula shown). Prior and goal fields live only in the planner localStorage record; Clear All Grades keeps them.

v1_18 11/21/2026

Added grading policy rules per assignment group: drop lowest N, best N of M, late penalty (%/day with cap), score replacement, and extra credit. Group math now runs through computeGroupResult (late → replace → drop/best-of → extra credit), with a Policies menu, active-rule badges, assignment late/EC flags, and Target Forecaster notes when drop rules make the needed average approximate. Covered by new Vitest policy tests; legacy saves migrate empty policies on load.

v1_17 11/21/2026

Implemented Quality Foundation: extracted calculation and storage logic into standalone modules (src/calc.js, src/storage.js, src/constants.js), added a comprehensive test suite with 74 Vitest unit tests covering GPA math, unit weighting, and migration, automated Playwright browser smoke and accessibility checks, set up a GitHub Actions CI workflow, and added accessibility improvements (polite live toast announcements, keyboard group reordering, and reduced-motion support).

v1_16_4 11/20/2026

Fixed duplicate classes (such as CS 61A and DATA C8) appearing on open or after JSON import: saved data is now the only source once it exists, so older storage keys no longer re-add classes, and classes with the same ID or the same code, term and title are merged on load and import. Default examples are now CS 61A and DATA C8 only (MATH 54 removed), and the Restore Demo Courses message lists the examples it checks.

v1_16_3 11/18/2026

Set the release date for v1_1 through v1_12 to 11/16/2026 and switched all changelog dates (cards and raw log) to the mm/dd/yyyy format.

v1_16_2 11/18/2026

Removed hardcoded values from the Profile & Settings inputs (Display Name, Academic Email, Institution, and Major / Program now show placeholders only, and legacy filler values saved by older versions are cleared on load), added a release date to every changelog entry and raw log line, fixed the raw log so every entry renders inside its block, and made the Raw Plain-Text Changelog a collapsible dropdown.

v1_16_1 11/17/2026

Added a per-class P/NP checkbox next to Units that excludes P/NP courses from Term and Overall GPA while still counting their units toward total units, updated the GPA Planner with P/NP tags, P/NP grade dropdowns, and excluded P/NP counts in summary footers, pinned the + New Term button to the far right over a single horizontally scrolling term chip row with right-edge clearance padding, and widened Course Title by reducing Academic Term to half width.

v1_16 11/17/2026

Added per-class Units (0–20 in 0.5-unit steps, defaulting to 4 for new, duplicated, imported, and existing classes) and updated Term and Overall GPAs to be unit-weighted (excluding ungraded and 0-unit classes). Gradebook term tabs and All Terms now show total units alongside weighted GPA, and the GPA Planner includes a read-only Units column, weighted summaries, and a method note.
